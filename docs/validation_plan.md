# Validation plan

1. **Software verification:** units, input rejection, interpolation, geodesics, checksums,
   deterministic runs and network isolation.
2. **Canonical physics cases:** only after equations are cited and reviewed—uniform atmosphere,
   known wind projections, controlled gradients, flat/analytic terrain, obvious cutoff cases.
3. **Published research:** reproduce sufficiently documented NASA FaINT and ASCENT 042 cases.
4. **PCBoom matrix:** compare cutoff classification, limiting Mach, ground intersection, ray path
   and false-safe rate across Mach, altitude, bearing, weather and terrain.
5. **Flight test:** compare to measured, traceable cases when usable data and expert review exist.
